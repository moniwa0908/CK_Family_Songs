# CK Family Songs Ver.7.4.6

ランダム連続再生を作り直しました。

変更点:
- 登録済みYouTube動画を最初にシャッフル
- シャッフルした動画ID一覧をYouTubeプレーヤーへプレイリストとして一括登録
- 1曲終了ごとの独自処理ではなく、YouTube側のプレイリスト自動送りを利用
- 最後の曲まで行ったら再シャッフルして継続
- 再生中の曲に合わせて歌詞も自動切替
- 埋め込み再生できない動画は次へスキップ
- 「次の曲へ」「一時停止/再開」「停止」対応

- app.js
- service-worker.js
