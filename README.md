# Ver.7.6.1 直近ライブ自動移動版

ライブタブを押したら、実際のライブ一覧の中で
「今日以降で一番近いライブ」のカード位置まで自動で移動します。

変更:
- Ver.7.6.0の専用NEXT LIVEカードは削除
- 実際のライブカードまで自動スクロール
- HTML構造修正後の安定版をベースに実装
- ページ上端/下端を超えないようスクロール位置をclamp
- Firestore描画とSafariレイアウト確定後に再計算
- ライブカードは画面中央より少し上に来る位置

- index.html
- app.js
- style.css
- service-worker.js
