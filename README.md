# CK Family Songs Ver.7.4.2
ランダム連続再生の開始処理を修正しました。

原因:
YouTubeプレーヤーAPIを「連続再生」ボタンを押した後から読み込んでいたため、
iPhoneでは最初のタップ操作と実際の再生開始が切り離され、自動再生が止められる場合がありました。

修正:
- YouTubeプレーヤーをアプリ表示時に先に準備
- 準備完了後の「連続再生」タップで直接再生開始
- 動画終了時は次のランダム曲へ自動移動
- 再生不可動画は自動スキップ
- 準備状態を画面に表示

GitHubへ上書き:
- index.html
- app.js
- service-worker.js
style.cssは変更なしです。
