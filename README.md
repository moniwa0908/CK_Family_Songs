# CK Family Songs Ver.7.0 Part1（曲名データ拡充）

## 今回の内容
- 既存の初期曲データを拡充
- ユーザー提供スクリーンショットから確認できた曲名を追加
- 歌ネット掲載ページで正式表記を確認した曲名を反映
- 英字タイトルの主要曲にふりがなを設定
- 歌詞本文は収録していません

## GitHubへアップロードするファイル
- song-seed.js
- service-worker.js

既存の同名ファイルへ上書きしてください。
アップロード後、管理者ログイン → 曲一覧 → 「初期曲名を一括登録」を押してください。
すでに登録済みの曲は自動でスキップされます。

## 次のPart
Part2で残りの曲名確認・不足分・ふりがな精査を行います。
